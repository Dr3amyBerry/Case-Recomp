# Contributing / Contribuir a Case Recomp

**Estado de licencias (2026-10-08):** el código propio aún no tiene licencia general aprobada. Consulta [LICENSING_STATUS.md](LICENSING_STATUS.md). Este documento establece normas de presentación, **no concede una licencia de código, no transfiere derechos de autor y no crea un CLA**.

## Español

Antes de proponer código o problemas:

1. Usa exclusivamente código original que puedas contribuir legalmente, o un fragmento de terceros acompañado de su procedencia, licencia exacta y requisitos de atribución. No supongas que ejecutar ProjectorRays o LibreShockwave hace que su código sea reutilizable en Case Recomp.
2. **No envíes** instalaciones de videojuegos, EXE, CCT, ZIP Director, sonidos, imágenes, fuentes, scripts Lingo recuperados, partidas o capturas de contenido comercial. Para los tests públicos usa archivos y recursos **sintéticos**.
3. No pegues claves, direcciones privadas, datos personales ni logs con contenidos propietarios en issues o pull requests públicos.
4. No afirmes que Case Recomp es un producto oficial de Big Fish Games u otro titular. Los nombres de títulos solo identifican compatibilidad.
5. No implementes funciones destinadas a eludir activaciones, protecciones o DRM sin revisión legal específica y autorización de mantenimiento.
6. Mantén cambios pequeños, documentados y comprobables; respeta el desarrollo en `main` salvo indicación expresa del mantenedor.
7. **Antes de incorporar aportaciones sustanciales de una persona distinta del titular**, documenta la titularidad de esa aportación y qué permiso escrito concede al proyecto para publicarla y eventualmente licenciarla. No inventes una cesión ni presupongas una licencia implícita.

Para incidencias generales: https://github.com/Dr3amyBerry/Case-Recomp/issues ; para consultas confidenciales o de derechos: **contact@rigorcore.com**. No publiques información privada en issues.

## English

The project's own source is not yet covered by a chosen general licence. This guide is **not a code licence, copyright assignment, or contributor licence agreement**. Read [LICENSING_STATUS.md](LICENSING_STATUS.md).

Submit only code and synthetic test fixtures you have the right to contribute. Do **not** upload original games, converted ZIPs, extracted media/scripts, copyrighted screenshots, private saves, passwords or personal data. Document the exact provenance and licence of third-party code; executing external tools does not automatically give permission to copy their source. Do not imply affiliation with game rights holders or add DRM circumvention functionality without specific legal review. Document ownership and explicit permission before merging substantive third-party contributions.

Public bugs: https://github.com/Dr3amyBerry/Case-Recomp/issues ; confidential legal/privacy matters: **contact@rigorcore.com**.
